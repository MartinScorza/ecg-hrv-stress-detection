# Media

This directory is reserved for publication-safe figures created specifically for the repository.

## Recommended visuals

- system architecture diagram;
- raw-versus-filtered ECG using synthetic or publication-authorized data;
- ECG with detected R peaks;
- RR/NN tachogram using synthetic or publication-authorized data;
- time-domain HRV comparison;
- AR spectral-density example with VLF/LF/HF bands;
- exploratory decision-tree visualization with an explicit small-sample / no-independent-validation caption.

## Publication rule

Do not copy third-party illustrations directly from the academic report unless their redistribution license has been verified.

Do not publish raw participant ECG or participant-level plots until data-publication authorization has been verified.

The Mermaid diagram in the root README provides a publication-safe architecture visual without redistributing report artwork.

# Original academic report

The original BM04 report was used to audit and document this repository but is **not redistributed here by default**.

Reasons for keeping the report out of a future public release include:

- it contains participant-level physiological result tables;
- it contains figures reproduced from external sources;
- it includes institutional branding;
- redistribution rights for all included third-party material have not been verified.

The public repository should instead contain original documentation written specifically for GitHub and only publication-safe figures.
